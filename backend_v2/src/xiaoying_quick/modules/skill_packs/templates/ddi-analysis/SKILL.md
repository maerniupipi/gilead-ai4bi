# DDI分析

用于用户要求的DDI报表或DDI表现分析；通过与查数相同的工具链先取数，再按证据下钻。不要创建洞察子Run或独立编排。

## 数据口径

- 以附带数仓说明为准。sales_target逻辑数据集保留行级权限；不得绕过权限直接读sales_target_ai4bi。Daily、Monthly不可混加。
- 日纯销：v_ai4bi_ddi_sales，CNY=SUM(sales_qty*price_latest)，USD=SUM(sales_qty*asp_price)。通过prod_code_codi关联prod_master；品牌并不唯一，按品牌关联时先去重。
- 区域关联使用业务year_month+hco_code并限定TA/BU，避免多对多。权限使用系统当前生效快照月；DDI权限机构字段为affiliate_hco_code。不得因报告筛选增加访问权限。
- teri_hierachy使用数据库实际拼写。data_range_config决定最新数据范围。ddi_coverage.coverage可能大于1，不自行截断或用于未经确认的外推。
- 数量与金额均可展示：实际、目标、达成率；月度/季度累计/年度累计同比；上季度环比。达成率=SUM(实际)/NULLIF(SUM(目标),0)，同比=(本期-同期)/同期，环比=(本期-上期)/上期。分母为0或历史缺失显示“—”。不要平均行级比率。
- 日明细没有目标和历史同期时，补查相应数据后在相同粒度对齐，不能把月目标重复写到每条日交易上。未取得目标/同期则保留缺失提示。

## 报告与图表

使用html模板技能和render_report工具。默认标题“DDI商业表现分析”，包含：

首次取数优先取得一份统一粒度的报表数据：月份×大区×品牌×渠道，带实际金额、数量、目标以及可比同期/上期。月份必须出现在查询列与GROUP BY中，不能只取整个年度按大区品牌的合计去画月度趋势。筛选字段必须同时出现在这份查询结果中。
标准看板不设TopN或LIMIT 200，所有筛选组合应完整保留；报告数据容量为1500KB，通过独立接口加载。明确向实验室要求完整聚合结果且不要限制行数。若源查询确实截断，必须提示范围，不能称全国总额。

不要为了每张图分别取很多不兼容的汇总，再交给模板拼接。模板只能选择一份已核验结果。用query_db返回的query_index指定源；字段报错时检查实际可用列，一次补查完整所需维度，禁止重复相同失败参数。

1. KPI：销售金额、销售数量、目标达成率、同比、环比；标注币种、期间和数据来源。
2. 实际与目标趋势（折线/柱线），按日、月、季度、年度切换；提供MTD/QTD/YTD累计范围。
3. 区域/品牌目标达成（水平条形及100%参考线）。
4. 区域/渠道同比增量贡献（正负条形，净变化为分组差额之和）；没有可比数据时显示构成占比而非伪造归因。
5. 明细表可切换维度、排序、编辑显示字段，日/月/季/年聚合与上方筛选联动。
6. 两至三条图文结论区分已核验事实、归因假设与建议，明确下钻证据和未验证项。

筛选建议：期间、大区、品牌、终端类型/渠道。金额支持CNY/USD（仅在数据中确有相应字段时开放）；数量单独切换。筛选后所有图表、KPI、表格和动态摘要必须使用同一数据子集。
