# html模板

当用户请求报表、看板、图文洞察或修改报告时使用。该技能只决定报告的内容结构与呈现，不替代查询、权限或数据核验。

## 呈现

使用共享render_report工具，传入设计配置而不抄写行数据。服务读取query_db的完整已保留结果；HTML由受控模板渲染，不接受任意模型脚本。样式由前端reports/template.js统一实现，预览和下载使用相同模板。

生成有图文解读的报告时，分两步使用同一工具：先传入设计并设置findings=[]，取得工具返回的完整视图和分组核验；再依据这些真实汇总补写2—3条findings并再次render_report。不能用query_db正文前30行的预览去推断总体金额、比例或贡献。第二次调用沿用同一报告，保持筛选和字段。数字引用必须与返回的核验值一致；没有核验数据时只写不带数字的待验证假设，不能标作已核验事实。
注意差额符号：图表与工具的“目标差额”为实际−目标，负数表示未达；“缺口金额”为目标−实际，正数表示缺口。达成率小于100%的分组不能写成超额。写完图文结论后核对这一定义。

- 吉利德品牌红、浅色画布、轻盈半透明材质和圆角面板；正式而清晰的业务语气。图表使用品牌红、青色正贡献与灰蓝比较线，提供渐入、柱形生长和数值过渡，并遵循减少动态效果设置。使用几何BI标识，清晰的数据单位与可读的中文标签。
- 结构：报告名和数据标识→期间/维度筛选→关键指标→宽幅趋势→达成和贡献图→动态摘要与证据结论→可排序明细→来源和缺失口径。
- 分析字段按实际查询列指定。metrics可映射qty、amount、amount_usd、target、target_usd、qty_target、prior、prior_usd、qty_prior、previous、previous_usd、qty_previous；缺少映射则不展示虚假值。
- columns为{key,label,format}数组；visible_columns控制显示字段，filter_fields控制筛选字段；dimension控制对比维度，date_field用于时间聚合，period为day/month/quarter/year；current_period形如2026-09，window为period/mtd/qtd/ytd，metric为amount/qty/amount_usd。
- 模板内置衍生字段：_achievement为汇总达成率，_yoy为同比，_qoq为环比，_share为该行销售额占当前筛选范围合计的比例。增加“销售占比”直接显示_share，不再询问分母；用户明确指定全国/分品牌等不同分母时再重新核验。
- 没有日期字段时显示按当前维度的实际与目标对比，不提供无效时间筛选；缺少某项非必要指标时，选择可核验的目标差额、未达分组或结构贡献作为辅助指标。
- 标准比例列使用模板_achievement/_yoy/_qoq/_share重算，避免把SQL返回的行级比率累加。
- 趋势与目标、横向达成对比、正负贡献和表格统一重算。未知或为零的比较基数显示“—”；空筛选显示明确空态，不能残留上一轮结论。
- 不依赖外网CDN，HTML下载保留筛选、图表、字段编辑和CSV导出。下载文件自然语言输入提示回到应用对话修改，不伪装成离线大模型。

## 自然语言修订

通过render_report的reuse_previous和design补丁保留同一报告的身份并递增revision。只改标题/颜色/字段显示时不重复查数；字段不在原数据里或筛选扩大范围时先补查。不要在补丁中插入rows。

界面会把用户当前筛选作为report_context传回会话。它只是显示上下文，不扩大授权、不替代数据源事实。修改后维持已有筛选，除非用户要求调整。所有文字经过转义，HTML模板不能读取父页面凭证。
