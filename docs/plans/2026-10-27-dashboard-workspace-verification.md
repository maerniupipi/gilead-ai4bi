## 参考与实现

参考 `/Users/shaox/Desktop/罗氏/ai4bi_loop/new_loop` 中的 `DashboardsView.vue`、`CustomBoardView.vue`、`AddChartToBoardDialog.vue` 和 `custom_dashboards.py`，采用主题卡片、选择已有看板 / 新建并添加、服务器解析来源图表、持久保存快照的流程。参考项目自定义看板主要为创建者私有，本次补充了整份看板的查看和编辑授权。

入口为 `/#/workspace`，详情为 `/#/workspace/:id`。收到共享的账号可直接通过链接登录后查看，不需要先获得来源 Chatbot 的查询权限。

## 功能验证

- DDI HTML 中的「加入看板」「保存指标卡」「保存趋势图」「保存贡献图」使用已存报告版本和当前视图。普通问答图表保存当前选中的 ECharts 样式。
- 支持创建和编辑主题看板、搜索、我创建的 / 共享给我分类、改图表标题、拖动与上下移动、半宽 / 整行布局、移除和取消编辑。
- 同一来源与筛选重复添加会去重。创建并收藏为原子操作，来源不合法不会留下空看板。
- 创建者管理授权与删除；可编辑成员可添加自己的问答图表及编辑内容，不能重新收藏他人原始运行或修改授权；可查看成员只能读取。
- 共享单图保存聚合后的图上数据，整份报告按收藏筛选和期间裁剪数据。原始 SQL 不进入快照；范围变化时移除旧文字结论和副标题。
- 所有查看和修改接口验证后端权限。未授权和已撤销账号读取返回 404，查看者修改、编辑者管理授权或删除返回 403。并发版本不一致返回 409，保留当前内容。

## 接收者权限验收

使用独立 SQLite QA 服务和四个隔离账号，在浏览器分别验证创建者、查看者、编辑者和未授权人员。该环境与正常业务库分离。

- 查看者没有 DDI Chatbot 权限、数据访问范围为 deny，仍能通过看板授权查看被分享的快照；原始运行访问为 403。
- 查看者页面没有编辑或授权按钮，直接请求修改也返回 403。
- 编辑者修改标题后保存、刷新成功；授权接口和删除整份看板返回 403。
- 未授权账号即使知道完整链接也无法读取。
- 创建者撤销后，查看者刷新页面和编辑者再次请求均无法读取。

这些流程同时检查构建后的页面，避免只验证开发环境。
