# 看板工作台 Implementation Plan

**Goal:** 将 DDI 自定义报告和正常问答图表收藏到主题看板，并为整份看板配置指定人员的查看或编辑权限。

**Architecture:** 参考 `/Users/shaox/Desktop/罗氏/ai4bi_loop/new_loop` 的自定义看板卡片、添加图表选择器和来源快照。沿用当前单机配置架构，以独立 SQLite 保存看板、图表快照和成员授权。图表数据由后端从已授权运行的 artifact/event 解析，客户端仅传来源、图表类型及筛选配置；所有看板接口检查创建者或显式成员角色。

**Tech Stack:** Vue 3、现有 ECharts 与 HTML 报告模板、FastAPI、SQLite、现有账号体系、pytest / node:test / Playwright。

## 产品范围

- 工作台集中展示我创建的和共享给我的看板，支持搜索、新建、编辑标题/说明/主题、删除与复制分享链接。
- 普通问答可以把当前图表加入已有看板，或新建并添加。DDI HTML 提供指标卡、趋势、贡献和整份报告的收藏入口，保留当前筛选、统计范围及样式。
- 看板图表为明确标记的保存快照。单图收藏只保留图上数据；整份报告只保留收藏筛选内的数据，移除原始 SQL、无关文字结论。原对话后续变化不会悄悄覆盖看板。
- 创建者管理成员授权；可查看成员只读，可编辑成员能添加、移除、改标题、调整顺序和宽度。成员不能转授权限或删除整份看板。撤销授权后下一次接口读取即失效。
- 看板共享只授权已保存的快照；原始对话、实验室和数据源权限继续独立检查。接收者即使没有对应 Chatbot 入口，也可以从登录后的工作台查看已获授权看板。
- 分享仅发生在产品内部，不发送邮件或外部消息。

## 实施

1. 新增 `application/workspace_assets.py`：校验来源、保存筛选、裁剪报告行、构建趋势/贡献/KPI 快照；后端解析已存图表事件，禁止任意客户端 chart/HTML 注入。
2. 新增 `infrastructure/workspace.py` 与 `api/routers/workspace.py`：看板 CRUD、添加图表、布局、成员目录和授权。原子创建并收藏、去重、版本冲突与越权检查。
3. 新增工作台列表与详情、添加看板弹窗、看板信息弹窗和授权弹窗。保持吉利德红、iOS 风格材质与响应式布局。
4. 接入侧边栏、登录后入口、分享深链接；为 AnswerCharts 和 ReportFrame 增加收藏事件。DDI 模板增加收藏按钮，工作台内报告不显示追问和再次收藏入口。
5. 自动检查创建/去重/筛选裁剪/未授权/查看/编辑/撤销/版本冲突，并完成实际 admin 收藏、布局、授权与刷新验证；使用隔离账号验证真实权限边界，检查手机端和生产构建。

## 验收

保留已有 Chatbot、DDI 问数、洞察、技能与历史记录。工作台刷新后保持内容；DDI 和普通图表都能加入同一个主题看板；获授权成员可按角色使用，未授权或已撤销成员无法读取快照。
