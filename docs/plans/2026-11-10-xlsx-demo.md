# XLSX 问数演示 Implementation Plan

> **For Claude:** Use the existing coding workflow to implement and verify this plan task by task.

**Goal:** 启动一个只提供 XLSX 问数、图表与看板的演示环境，创建指定的普通用户账号。

**Architecture:** 用运行配置启用 XLSX 单助手模式，保留既有配置以便恢复。新增按账号隔离的工作簿上传、预览与移除接口；查询只读取运行创建者上传的文件。复用现有只读 WorkbookLab、图表和看板快照能力。

**Tech Stack:** Vue 3 / Vite / ECharts；FastAPI / SQLAlchemy / SQLite / openpyxl；现有模型配置。

---

### Task 1: 后端工作簿与目录
- 修改 `bootstrap/settings.py`、`infrastructure/chatbots.py`、`api/routers/chatbots.py`。
- 单助手模式只公开 `xlsx` 助手；支持无文件时进入上传流程。
- 工作簿按账号绑定，原子校验总数不超过 10；单文件 <= 10 MiB，最多 5 个 sheet（包含空 sheet）。提供列表、上传、移除，校验账号和助手访问权。
- 验证未登录访问、跨用户读取/删除、文件数量与大小、sheet 数上限及移除后重新上传。

### Task 2: 问数与图表
- 修改 `bootstrap/container.py` 与 `api/routers/chat.py`。
- 查询上下文从运行创建者的工作簿构建；无文件明确提示先上传，禁止回落其他数据源。
- 复用模型生成只读 SQL、ECharts 和加入看板功能，验证另一个用户的数据无法进入查询上下文。

### Task 3: 用户界面
- 新增 `components/chat/WorkbookPanel.vue` 与 `utils/workbooks.js`；扩展 API 包装。
- `store.js` 自动进入唯一 XLSX 助手；`Sidebar.vue` 只保留问数与看板入口；`ChatView.vue` 提供持续可用的文件入口和上传空态。
- 沿用项目的红色商务视觉，显示文件计数、大小、sheet 预览、上传进度与逐文件错误。
- 前端校验类型、大小、总数；sheet 数由后端读取文件内容校验。

### Task 4: 启动与演示账号
- 在本地运行配置启用单助手模式，保留已有配置更改。
- 通过现有身份服务创建 `xlsx_demo` 普通用户，密码只通过本次配置流程使用。
- 验证登录、上传、真实模型问数、图表、加入看板、刷新持久化，并清理临时验收文件。
- 运行后端相关测试、前端测试及生产构建；保持项目运行并给出访问地址。

### Task 5 表格展示与独立收藏

- 回答正文的 Markdown 表格直接展示，为每张表增加独立的加入看板入口。
- 抽取共用数据表组件，用于图下明细与看板表格卡片，保留排序、分页、CSV 和预览提示。
- 增加正文表格和图表数据表两类收藏来源，由后端从当前用户的已保存回答或图表结果生成快照。
- 兼容已有问答与图表快照，确保最终图表附带可见的数据表，收藏和刷新后数据一致。
- 增加默认展开、来源定位、重复收藏、跨用户权限和旧快照的回归验证，并在浏览器检查实际效果。

### Task 6 历史会话与滚动位置

- 打开历史会话时先进入对话并显示加载状态，基础消息返回后一次性定位到最新用户问题，保留指定问题的跳转入口。
- 运行记录按最近回答优先在后台恢复，限制并发并支持切换会话时取消，避免阻塞进入对话。
- 历史回答与图表进入视口时分步渲染，HTML 报告生成与加载期间显示占位。最后一条回答预留一屏高度，确保最新用户问题可以稳定定位。
- 移除流式内容、步骤、状态和图表变化触发的自动滚动，验证生成过程和延迟渲染后阅读位置稳定。
