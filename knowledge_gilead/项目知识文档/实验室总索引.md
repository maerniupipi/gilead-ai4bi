> **职责：路由**（唯一实验室判定、关键词/KPI 词表）。不问业务公式、不写域内 SQL。

## 1. 路由表

| lab_id（兼容） | 业务显示名 | 一句话定位 | 典型信号 |
|---|---|---|---|
| `actual` | 吉利德 DDI | DDI 销售金额/数量、指标、达成、同环比、当月日累计（MTD） | 达成、指标、销量、盒数、DDI、MTD、同比、环比 |

**说明**：`actual` 是实验中心凭证槽位与接口兼容标识，**不是**旧项目「Actual 开票实验室」。对外统一称吉利德 DDI。  
知识文档路径：`labs/ddi.md`。`ask_lab(lab_id="actual")` 与读该文档对应同一实验室。

## 2. 判别流程

```
问题
 ├─ 命中 §3 DDI KPI / 维度信号 → 路由 `actual`（吉利德 DDI）
 ├─ 一句多问 → 拆成原子查询，仍全部落本实验室
 ├─ 口径不清 → 先澄清（金额 vs 数量、月 vs 日累计、同比 vs 环比）
 └─ 命中未配置主题（Demand / 外部市场）→ 说明本 POC 不支持，禁止改绑其它实验室
```

本 POC **没有** demand / ext_simple / ext_complex。不得借用强生或其它项目的 API 调用 ID，不得为答题切换旧业务库。

## 3. 关键词与 KPI 词表（路由用）

公式权威见 `业务知识.md`；别名细节与 SQL 见 `labs/ddi.md`。

### 3.1 维度信号（命中 → 本实验室）

| 类 | 关键词（节选） |
|---|---|
| 时间 | 月、YTD、QTD、当月、日累计、MTD、截止日、最近完整月 |
| 产品 | 品牌、品规、TA、治疗领域 |
| 组织 | 全国、大区、region、BU、TS、ASM、RSM、SD、辖区 |
| 地理 | 省、市、省份、城市 |
| 机构 | 医院、HCO、终端 |
| 市场/渠道 | 核心市场/CSO/多渠道；医院准入/药房/电商；医院/零售药店/电商平台；「DDI」作日累计主题词 |

### 3.2 支持的 KPI（仅下列；已合并同义）

| # | KPI | 别名（路由匹配） |
|---|---|---|
| 1 | 销售金额 | 销售额、金额、Actual、Act Value、卖了多少钱、业绩、销量（未标明盒数时） |
| 2 | 销售数量 | 盒数、数量、Qty、Vol、卖了多少盒 |
| 3 | DDI MTD Actual | DDI当月日累计销售金额、当月日累计金额、MTD Actual、按日累计金额 |
| 4 | Target | 销售指标、指标、目标、要做多少；含数量指标、金额指标 |
| 5 | A/T% | 达成率、完成率、a/t、完成进度、达成怎么样 |
| 6 | YoY GR% | 同比、同比增长、同比增速；含 Month / QTD / YTD 同比 |
| 7 | DDI MTD YoY GR% | DDI当月日累计同比、MTD 同比 |
| 8 | MoM GR% | 月环比、环比上月 |
| 9 | DDI MTD MoM GR% | DDI当月日累计环比、MTD 环比 |
| 10 | QoQ GR% | 季度环比、上季度环比、环比上季 |

**明确不支持**：Demand 流向、外部市场份额/EI、Target GR%、HoH、贡献率（Con%）、任意未列出指标。

## 4. 易混案例

| 问题特征 | 正确处理 | 说明 |
|---|---|---|
| 全国达成是多少 | `actual` · A/T% | 默认金额达成 |
| 卖了多少 / 销量 | `actual` · 销售金额 | 要盒数才走销售数量 |
| DDI 当月累计多少钱 | `actual` · DDI MTD Actual | 走日表，勿用整月 Monthly 冒充 |
| 同比是多少 | `actual` · YoY GR%（Month） | 未说窗口时默认月同比 |
| 上季度环比 | `actual` · QoQ GR% | 与月环比区分 |
| 流向 / Demand | 不支持 | 本 POC 未配置 |
| 市场份额 | 不支持 | 本 POC 未配置外部市场 |

## 5. 证据与时间（路由侧提醒）

- `ask_lab` 取同次 trace 与 SQL；`query_db` 只消费该次已执行的相同 SQL 结果。
- 默认最近完整月 **202608**、粒度 **Monthly**；显式按日 / MTD 用截至 **2026-09-03** 的 DDI。
- 层级表含未来月（如 203603），禁止裸用 `MAX(year_month)` 当业务截止。
