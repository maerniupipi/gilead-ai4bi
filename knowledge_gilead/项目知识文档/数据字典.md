# 吉利德 POC MySQL 六表数据字典（DDI 精简）

> 描述当前已落库的合成模拟数据（库 `gilead_poc`）。**只收录主链路理解 DDI KPI 所需字段**；完整列清单可查附件/源材料，不必全部写入知识库。  
> 最近完整月：**202609**；最新 DDI 日：**2026-09-30**。数量单位盒；人民币金额单位元。Monthly 与 Daily **不可混加**。

生产侧「逻辑数据集 + 区域授权 CTE」属后续验收项；当前联调为六表物理表 SELECT 只读。MySQL **无** `public` schema。

---

## 表一览

| 表 | 用途 | 主链路角色 |
|---|---|---|
| `sales_target_ai4bi` | 月/日销售实际与目标事实 | 销售金额/数量、Target、A/T%、月级同环比 |
| `v_ai4bi_ddi_sales` | DDI 日纯销明细 | DDI MTD Actual 及 MTD 同环比 |
| `prod_master` | 产品 / 品牌 / TA | 日明细→品牌桥；品牌去重后关联 |
| `teri_hierachy` | 月度 HCO–辖区–人员快照 | 大区/省/市/人员维度下钻 |
| `data_range_config` | 单行截止期控制 | `{max_month}` / `{max_ddi_date}` |
| `ddi_coverage` | 品牌覆盖系数 | 仅覆盖类问题；默认 KPI 不用 |

## 关联与查询规则

1. **月度 KPI**（金额/数量/指标/达成/月级同环比）：`sales_target_ai4bi` + `data_type='Monthly'`；大区用 `region`，通常不必连层级表。
2. **截止月**：读 `data_range_config.max_daily_yearmonth`。
3. **DDI MTD**：`v_ai4bi_ddi_sales`，金额 `SUM(sales_qty * price_latest)`；品牌经 `prod_code_codi`→去重后的 `prod_master`。
4. **日明细连层级**：至少 业务月 + HCO + TA + BU，禁止只按 HCO。
5. **达成率 / 增长率**：分母为 0 → NULL（不适用）；禁止编造 0%。
6. **证据**：实验中心执行 SELECT；本应用 `query_db` 只读同次 trace 中相同 SQL 的结果。
